# Polices

La mise en page utilise **Zeitung Pro** en trois graisses. Ces polices ne sont pas libres et
ne se trouvaient pas dans le dossier InDesign : elles ne sont donc pas fournies.

Tant qu’elles ne sont pas disponibles, l’outil utilise la police libre **Mulish** (dossier
`secours/`, licence SIL OFL), de largeur proche, pour que la mise en page reste juste.

## Option 1 — dans le navigateur (recommandé)

Bouton **Polices** en haut de la page → choisissez les 3 fichiers. Ils restent dans votre
navigateur et ne sont **pas publiés** sur Internet. À refaire sur chaque ordinateur/navigateur.

## Option 2 — dans ce dossier

Déposez ici, avec exactement ces noms :

- `ZeitungPro-Regular.otf`
- `ZeitungPro-Semibold.otf`
- `ZeitungPro-Bold.otf`

(`.ttf` accepté aussi). ⚠ Sur GitHub Pages, ces fichiers seront téléchargeables par n’importe
qui : vérifiez que votre licence le permet (en général, ce n’est pas le cas).
