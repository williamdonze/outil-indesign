# Logos du cercle rouge

Déposez ici vos **deux options** de logo, avec exactement ces noms :

| Fichier | Option dans l’interface |
|---|---|
| `logo-1.png` **ou** `logo-1.jpg` | Logo 1 |
| `logo-2.png` **ou** `logo-2.jpg` | Logo 2 |

- Formats acceptés : PNG ou JPEG (pas de SVG). Un seul fichier par numéro.
- Image **carrée** de préférence (400 × 400 px ou plus) : elle est centrée et découpée en rond dans le cercle rouge, comme dans le document InDesign (`logo-1.jpg` est l’icône d’origine).
- Après avoir ajouté ou remplacé un fichier, faites un commit/push : GitHub Pages met le site à jour en une minute environ. Rechargez la page.
