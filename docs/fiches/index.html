      Polices

      Police utilisée actuellement :

      La mise en page utilise Zeitung Pro en trois graisses : Regular, Semibold et Bold. Ces polices ne sont pas libres : elles ne sont pas fournies avec le site. Deux façons de les ajouter :

      1. Dans ce navigateur (recommandé) : choisissez les fichiers .otf ou .ttf ci-dessous. Ils restent sur cet ordinateur et ne sont pas publiés sur Internet.
      2. Dans le dossier du site : déposez ZeitungPro-Regular.otf, ZeitungPro-Semibold.otf et ZeitungPro-Bold.otf dans docs/fiches/fonts/. Attention : sur GitHub Pages, ils seront téléchargeables par tout le monde (vérifiez votre licence).
